# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Project Overview

This project focuses on streamlining the IT procurement process for standard laptop orders using ServiceNow Flow Designer.

The solution automates the activities that take place after a service request is approved, including creating a Catalog Task, updating the Short Description, and assigning the task to the Hardware assignment group.

## Problem Statement

Standard laptop procurement can involve repetitive manual activities after a request is submitted and approved.

These activities include:

- Processing the approved request
- Creating a Catalog Task
- Updating task information
- Assigning the task to the appropriate team

Manual processing can increase effort and may result in delays or inconsistent task handling.

## Proposed Solution

The proposed solution uses ServiceNow Flow Designer to automate the post-approval procurement workflow.

The automated process is:

Requester
↓
Service Catalog
↓
Standard Laptop Request
↓
Approval Process
↓
Request Approved
↓
Flow Designer
↓
Create Catalog Task
↓
Update Short Description
↓
Assign to Hardware Group
↓
Hardware Team

## Objectives

- Automate the standard laptop procurement workflow.
- Reduce repetitive manual processing.
- Automatically create Catalog Tasks after approval.
- Update the Catalog Task Short Description.
- Assign the Catalog Task to the Hardware group.
- Provide a structured procurement workflow.
